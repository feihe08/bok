# 剩余问题清单

本文记录 2026-08-04 UI、任务与扩展交互审查后仍未处理的事项。本轮只记录，
不代表已经排期或实现。

## 数据安全与稳定性

- Chrome 书签栏和 Bok 标签页保存记录已支持写入本机或 iCloud Drive 的 JSON 备份；
  从备份文件预览和恢复数据仍需后续实现。
- 为保存、打开、任务状态和浏览器标签组同步补充自动化测试。目前只有人工回归和
  `pnpm compile` / `pnpm build` 检查。
- 提升保存并关闭流程的幂等性或加入事务日志，减少保存成功但关闭中断后重复记录的
  风险。
- 后台操作失败时提供更明确的可见反馈和重试入口；部分失败目前只写入控制台。
- 数据量明显增大后，评估每次修改都重写完整 `sessions` 数据的性能；当前
  `revision` 只递增、不做写入冲突检测，增加第二个写入上下文前需要避免旧快照覆盖。
- 恢复副本目前以完整数组读后再写，并用短哈希去重；多个上下文同时发现不同损坏
  数据时存在低概率的追加覆盖或哈希碰撞风险，需要在恢复功能正式开放前加固。

## 标签组同步

- 明确活跃同步标签组中执行“将此标签页发送到 Bok”的产品语义：当前会把该标签保留
  在原 Bok 分组中；需要确认它是否应被视为普通关闭并从原组移除。

## 书签与导入能力

- 规划 Chrome 书签整理能力，包括重复识别与死链检查；当前仅保留未启用的入口，
  不申请 HTTP/HTTPS host 权限，也不会自动分析、删除或合并书签。
- 评估旧的 `SavedTab.tags`、`SavedTab.directory` 字段是否继续用于“标签页晋升为书签”；
  当前 Chrome 书签管理不读取或写入这些字段。
- 评估并实现 OneTab 文本导入。该能力不在当前 `requirement.md` 的既定范围内。

## 工程与发布整理

- 移除或正式启用模板遗留的 Google 页面 content script；当前暂不处理。
- 清理不再由保存页入口使用的旧 UI 文件，例如 `App.tsx`、`ActionMenu.tsx` 和
  `InlineEditor.tsx`。
- 更新包名、版本号、描述和 README，替换 starter 项目信息，形成可发布元数据。
- 设置页按原计划继续延后，等出现需要用户配置的选项后再实现。
